orbit-launcher · design presentation v3 · immersive flows

You never leave the ship.

v2's splash is locked — this pass makes the work screens live up to it. The terminal is never handed away: install.sh (and repair, and remove) runs inside a framed mission console within the app, its real output streaming in a bounded window, with a stage bar and an elapsed clock. The flow ends on a hero moment: the planet ignites.

01 Install — the mission console, live

orbit-launcher — install
ORBIT · Install — Standard 0:00
Preparing…
v0.1.0

install.sh runs in here, for real

  • The console is a real PTY viewport. orbit-launcher runs install.sh under its own pseudo-terminal and streams the genuine output into this frame — same bytes a bare terminal would get, just bounded and composed. The launcher already writes the full config beforehand, so the script needs no input once it starts.
  • The stage bar has no percentage. It advances when a known stage lands in the output (staged → validated → pulling → services → health), easing between stops. The only number anywhere is the elapsed clock, top right.
  • The current stage in words, bottom left — the status-line idea from v2, doing its real job: you can glance away from the scroll and still know exactly where you are.
  • Output is calm by framing: newest lines enter at the bottom, older ones fade under the top edge. The full transcript still goes to the log file — this window is for watching, not archaeology.
  • Same sky behind it, same rotation clock, sparse density — the mission console sits in the world, it doesn't replace it.

02 Repair — same console, amber discipline

orbit-launcher — repair
ORBIT · Repair — 2 services unhealthy 0:00
Diagnosing…
v0.1.0

Identical grammar, different weather

  • Repair is the same screen as install — console, stage bar, clock — recoloured amber (the new errored hue) while things are wrong, returning to the accent blue as they come right. A person who has installed already knows how to read a repair.
  • The header states the finding, not a feeling: "2 services unhealthy", counted from the same health probes the real diagnosis runs. It updates live as fixes land.
  • Diagnose before touching: the console shows the checks first, each with its verdict, then the interventions one at a time. Same honesty rule as remove: say what will happen, then do exactly that.
  • Ends in the same place: a successful repair flows into the ignition hero, because a healthy planet is the outcome either way.

v0.1.0

The console yields to the planet

  • The transition is the reward: when the health checks all land, the console and stage bar fade out, the sphere scales in at centre, and it ignites — ~1.4s, glow swelling then settling. This page plays it on load; reload to see it again.
  • The corona never rotates. Like the real one: four glow patches at fixed positions around the limb wax and wane on long offset cycles (29–53s), so the halo's brightness redistributes in place — it morphs, it doesn't travel. Nothing circulates, so nothing can read as "blobs going around a circle".
  • Streamers are soft bursts now, not lines. Seven wisps, each an S-curved arc rooted under the glow so its base vanishes into the halo; drawn as wide, heavily blurred bands at low opacity (peaks .2–.3), so they read as the corona itself reaching outward — no distinct edges anywhere. Each extends along its curve, holds, and retreats on its own 19–37s clock.
  • In the terminal: glow patches are per-cell brightness on a ring sampling 3–4 fixed angular gaussians with time-varying amplitude; wisps are precomputed curved cell-runs (4–7 cells, one gentle bend) revealed and hidden progressively from the root. Still just arithmetic on the existing tick; text cells untouched.
  • No verdict line. The sphere says alive; repeating it in a headline was noise. The URL is the hero — accent colour, its own row, copyable via the same OSC 52 path the remove flow already uses.
  • Actions are a menu, not a button row — stacked and centred exactly like the splash, same caret grammar: Get into Orbit, Terminal, Menu. Terminal quits the launcher cleanly into a shell — for the person whose next move is docker compose logs -f.
  • "Orbit achieved in 3m 42s" is the footer — bottom-left, same weight and colour as the version bottom-right. The moment is named where the chrome lives, not inside the celebration.
  • Repair ends here too — same screen, no elapsed-time line.

  • Errored is deep yellow-orange (#fb923c), not red. Red means stopped/failed; amber means up but wrong — the server is running, something needs attention. The limb stays lit because the planet genuinely is alive.
  • The errored splash preselects Repair the same way a detected deployment preselects Update today — the sphere says what's wrong, the caret already points at the fix.
  • Threshold: any failing health probe → errored. No partial shades, no traffic-light gradients — three states you can tell apart across the room.
